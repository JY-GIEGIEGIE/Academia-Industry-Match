## 交互证据

- **企业端浏览与上下文保留**：选需求 → 按最低适配度筛选 → 翻页 → 进详情 → 返回列表，对象、筛选条件和页码均保留。
- **科研端与双端一致性**：科研端选成果 → 看推荐需求 → 进同一配对详情页，两端展示内容一致。
- **空结果与重置**：拉高最低适配度到 100 分触发空状态，点重置后列表恢复。
- **缺失与失效状态**：切到未精排或失效配对时，风险与证据栏显示“待重算”，不绘制有效风险雷达图。
- **异常与恢复**：访问缺失记录或非法页码时弹出明确错误提示，可正常切回有效视图。
- **手机端交互**：窄屏下展开“当前资料与筛选”，切换对象并跳转详情页正常。
- **无障碍与数据边界**：键盘焦点跳转正常，窄屏整页无横向溢出；技术指标在缺资料时保持显示“尚未核实”，不给出达标结论。

## 视觉比较与修复

对照本轮文字线框和[设计说明](../DESIGN.md)逐项核查（本轮跳过图像生成，未做 Image Gen 参考图逐像素比对）：

| 比较点     | 线框要求与实际结果                                           |
| ---------- | ------------------------------------------------------------ |
| 布局       | 桌面左侧当前资料、右侧横向列表；详情左右对照，手机上下排     |
| 配色       | 冷灰底/白内容/深蓝文字/青绿操作保持一致；风险用琥珀色        |
| 文字       | 主标题28px、清晰的层级；中文说明与演示分析均有明确标记       |
| 容器与间距 | 285px侧栏、28px间隔、小半径；条目使用分隔线而非厚阴影卡片    |
| 图标       | SVG方向/信息/来源图标统一笔画，无无效导航和装饰动画          |
| 手机排版   | 修复详情“/100”换行；320/375/760/1280复查保持一行且无页面溢出 |
| 状态       | 风险缺失或失效不绘制雷达结论；来源与补充信息可展开           |

当前未发现阻断交付的布局或交互缺陷，具体视觉感受可由组员本地启动页面确认。手机端技术指标表只在自身容器内横向滚动，不会撑宽整页。

## 数据边界

- **本轮前端演示集**：4 篇真实论文 + 5 条模拟需求组合成 20 条唯一配对，聚焦电解质方向。
- **与 S-02 全库的区分**：数据取自 S-02 v0.1，全库的 300 篇成果 / 100 条需求 / 25 家企业并未放进前端仓库；前端中论文摘要最多留 600 字符，列表预览最多 300 字符。
- **脱敏与模拟说明**：样例不包含作者、机构、真实企业名或联系人。中文说明和演示分类由 Codex 根据原标题与采集方向整理；分数、理由、风险和模型标识均为演示固定值，没有跑真实匹配算法。真实论文目前处于知识产权未知、TRL 待评估、指标未核实状态。
- **联调与任务边界**：真实联调需等后端 API、正式匹配结果和数据服务就绪。前端页面完成不代表组员个人补写 20—30 条需求的任务已完成或取消。
