# 本轮设计依据

前端采用清爽的工程工具风格，按登录身份展示科研端或企业端。文字线框记录布局与视觉参数。

## 视觉系统

- **配色规范**：页面底色 `#F4F7FA`，内容区 `#FFFFFF`，主文字 `#20364F`，主操作色 `#197B6A`，次文字 `#637489`，边框线 `#DDE5EE`。风险警示用克制的琥珀色，避免把绿色用作“高风险”。
- **字体与字号**：中文优先调用本机 `Microsoft YaHei UI`，回退至 `PingFang SC`/`Noto Sans SC`。主标题 `28px`，正文约 `15px`，辅助说明 `12—14px`。主体内容左对齐，分数用等宽数字对齐比较。
- **容器与细节**：容器圆角 `6px`，输入框与按钮圆角 `4px`。页面靠横向列表、双栏对照和排版层级来组织信息。

## 推荐页

```text
产学研对接       主导航                  当前角色 · 用户名 · 退出登录
演示说明：需求、企业和分析的模拟口径

当前资料（左285px）                     为你推荐（右侧自适应）
当前角色的发布资料                      结果数量 / 最低适配度
选择当前资料                           横向推荐列表
当前资料摘要及约束                     标题、方向、简介、推荐理由
结果状态                               右侧适配度、风险状态、查看详情
                                       分页 / 分数含义说明
```

科研账号的资料区标题为「我的成果」，企业账号为「我的需求」。说明句交代数据范围、匹配对象和分数含义。

## 详情页

```text
产学研对接                             返回推荐列表
演示说明
匹配详情                               演示适配度
科研成果（左）                         企业需求（右）
原始标题、中文说明、成熟度              痛点、指标、企业化名、合作方式
原文摘要与来源                         其他资料
为什么推荐 / 原文摘录 / 技术指标对照
四项风险：小雷达图 + 四维文字解释
综合提醒与规避建议
资料来源与版本（可展开）
```

来源摘要和补充资料支持折叠展开。页面上的演示分数、风险提示和中文生成内容都带有对应标记；遇到风险无数据或配对失效时，隐藏雷达图结论；缺核查数据的指标保持原状，不强行判为达标或不达标。

## 响应与交互

桌面端最大内容宽度 `1280px`（两侧各 `40px` 内边距），视口宽度 `760px` 及以下转为单列布局。手机端顶部显示角色与账号，主导航换行，资料区收拢为可展开折叠面板，推荐条目的操作按钮移到底部。手机端进入详情页时，双方资料改为上下排列，四项风险的雷达图排在文字解释之前，技术指标表格各自在容器内横向滚动。所有按钮和链接保留键盘焦点，图表旁同步给出文字数值与风险方向说明。

账号角色决定 URL 中的 `view`。从详情页返回列表时恢复当前角色下的对象、分数门槛、结果状态和页码。

## 视觉验收方法

因为本轮未生成概念图，视觉检查直接对照本文件的参数和文字线框，分别核对桌面端与手机端截图，未做与 Image Gen 参考图的逐像素比对。检查范围包括布局、文案层级、配色、字号、间距、容器、图标、响应式断点和交互状态。验收结果见[交付与验收记录](docs/交付与验收记录.md)，截图与浏览器记录存在仓库内 `frontend/docs/evidence/`，临时脚本不作为他人运行依赖。
