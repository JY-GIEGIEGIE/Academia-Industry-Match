## 填写规则

### 标签评测

- AI 列是当前抽取初标；人工列留空。
- 如果 AI 列正确：在对应人工列写 `OK`。
- 如果错误：写正确 code（多个用 `;` 分隔）；code 以 `data/spec/taxonomy_v0.1.md` 为准。
- 不确定：写 `unknown` 或 `待复核`，并在备注写原因。
- 每行三列都要有值；不要因为“看起来差不多”就写 OK，按技术内容判断。

### TRL 边界

- 根据摘要证据填 `1`—`9` 或 `null`；必须写依据（原文片段/试验阶段）。
- `null` 表示没有足够证据，不是失败。
- 参考：1—3 实验室/概念；4—5 实验室验证/小试；6 中试；7—8 示范/现场；9 量产。
- 不要为了凑完整而编造 TRL。
