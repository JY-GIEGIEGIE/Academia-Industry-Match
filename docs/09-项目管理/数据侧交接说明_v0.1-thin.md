## 1. 定位与核对结论

本文件把交接包内的 `README_交接.md` 和组长 2026-11-18 的冲刺公告，按仓库结构归位成一份可长期引用的交接说明。它记录**交接状态、读入顺序、核验结果和待确认项**；角色任务仍以 `AGENTS.md` 和 `docs/09-项目管理/数据侧分工安排.md` 为准，字段/枚举/评测口径仍以 `data/spec/` 为准，本文件不重复定义。

核对结论（2026-11-18，基于 `main@18f170e`）：

1. 交接包共 34 个文件；除 `README_交接.md` 和 `data/processed/` 下 2 个全量数据文件外，其余 31 个与仓库同名文件内容一致，差异仅为换行符/BOM。
2. 包内 `README_交接.md` 已按仓库文档规范整理为本文件，原包不再单独入库。
3. `data/processed/` 按仓库规范不入库；仓库只保留 20 条截断样例，**不要以为仓库里有完整数据**。
4. `docs/08-数据工作/数据工作拆解.md` 已删除，旧链接和 D0—D10 周排期不再使用；仓库内已无该目录引用。
5. 远程 `main` 已包含本次交接所需内容，接手前先拉最新 `main`，不要在旧分支上继续。

核对方法：对包内文件与 `HEAD` 同名文件做 BOM/换行归一化后比较 SHA-256；JSONL 逐行解析后按记录比较；CSV 比较表头与行数。包内 `data/processed/` 的 100 条与 `data/samples/` 的 20 条为子集关系，样例摘要截断至 ≤601 字符；20 条 query 的候选集和 50 对 pair 的成果/需求 ID 均能在现有数据中找到。

## 5. 统一口径

- **数据**：OpenAlex 主源；arXiv 备用；CNKI/万方不抓取；需求/企业为模拟数据，企业使用化名。
- **技术栈**：Python 3.11；PostgreSQL 16 + pgvector 0.8.x；BGE-M3 1024（备选 Qwen 1024），不得混维。
- **版本**：当前 `v0.1-thin`；扩量后的全量产物用 `v0.1`；匹配结果绑定 `dataset_version + taxonomy_version + embedding_model_version`。
- **历史材料**：开题报告、过程稿、产品需求分析只作历史材料；技术栈、数据、指标以 `data/spec/` 和 `docs/03-项目计划/数据口径更正记录_v0.1.md` 为准。

```bash
python -m compileall -q scripts
python scripts/data/validate_thin_slice.py --version v0.1-thin
# OK: thin slice matches the v0.1 contract.
# 警告：100 条均为英文，中文展示依赖后续生成的 capability_profile_zh
```

## 8. 注意事项

- 缺 Python、OpenAlex 网络、百炼 Qwen API key、PostgreSQL/pgvector、Embedding 任一项，先找贾越，**不要自己 mock 数据或改口径**。
- 不改 taxonomy 枚举和数据契约字段；确需改先找 DE/AI/BE2，并走变更控制。
- 不提交 `data/raw/`、`data/interim/`、`data/processed/`、`.env`、API key、完整摘要到公开仓库；样例摘要正文 ≤600 字符。
- 不编造标签、TRL、IP 状态或性能指标；无证据写 `unknown`。
- 分支、提交、PR 按 `docs/09-项目管理/仓库提交与管理规范.md`；`main` 受保护，不直接 push。
- 完整数据只通过交接包/私有存储分发；仓库样例不能用于验收。
- `data/raw/` 原始快照不在交接包内；需要复现抓取时，按 `scripts/data/README.md` 自行抓取，不要改抓取口径。
