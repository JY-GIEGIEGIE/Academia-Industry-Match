# 标签与画像文件的输入格式（2026-11-19）

> 适用：`achievements_labeled_v0.1*.jsonl`、`capability_profiles_v0.1*.jsonl`
> 依据：`data/spec/data_contract_v0.1.md` 第 4.3、4.4、4.5 节
> 作者：张小桐（BE2）｜请陈镇灏（AI）按此产出，导入侧按此解析

## 1. 两个文件的关系

| 文件 | 每行内容 | 落库表 |
| --- | --- | --- |
| `achievements_labeled_v0.1-thin.jsonl` | 一个成果 + 它的标签数组 + 抽取结果 | `achievement_tag`、`achievement_extraction` |
| `capability_profiles_v0.1-thin.jsonl` | 一个成果的能力画像文本 | `achievement_text` |

`achievement_id` 必须与 `achievements_clean_v0.1-thin.jsonl` 一致，否则导入报错。

## 2. `achievements_labeled_v0.1-thin.jsonl`

一行一个成果：

```json
{
  "achievement_id": "ach_openalex_W4210818813",
  "tags": [
    {
      "dimension": "tech_field",
      "code": "electrolyte",
      "is_primary": true,
      "confidence": 0.92,
      "evidence": "sulfide solid electrolyte with high ionic conductivity",
      "method": "llm",
      "model": "qwen3.8-flash",
      "prompt_version": "v1",
      "review_status": "pending"
    },
    {
      "dimension": "application_scenario",
      "code": "ev",
      "is_primary": false,
      "confidence": 0.7,
      "evidence": "for electric vehicle applications",
      "method": "llm",
      "model": "qwen3.8-flash",
      "prompt_version": "v1",
      "review_status": "pending"
    }
  ],
  "extraction": {
    "material_system": "硫化物固态电解质",
    "key_metrics": [{"name": "离子电导率", "value": 12, "unit": "mS/cm", "evidence": "12 mS cm-1 at 25 C"}],
    "process": ["球磨", "退火"],
    "trl": 4,
    "trl_confidence": 0.8,
    "trl_evidence": "assembled coin cell tested at laboratory scale",
    "ip_status": "unknown"
  },
  "extraction_run_id": "extract-20261120T101500Z",
  "model": "qwen3.8-flash",
  "prompt_version": "v1",
  "review_status": "pending"
}
```

规则：

- `tags` 可以是空数组（该成果没抽到标签），但覆盖率统计会单独报。
- `extraction` 可以是 `null`（该成果跳过抽取）。
- `tag_id`、`extraction_id` **由导入器生成**（`tag_{achievement_id}_{dimension}_{code}`、`ext_{achievement_id}`），你不用填。
- `dimension` 只能是 `tech_field`、`application_scenario`、`cooperation_mode`；`code` 必须在 `taxonomy_v0.1.md` 对应维度的枚举里。
- `tech_field` 每个成果**恰好 1 个** `is_primary=true`，最多 2 个 `tech_field`。
- `trl` 为 1—9 的整数或 `null`；非 `null` 时必须给 `trl_evidence`。
- 没有依据时 `confidence ≤ 0.4`，`review_status` 写 `pending`（表约束只允许 `pending`/`approved`/`rejected`；契约 6.3 提到的 `needs_review` 目前不在枚举里，先用 `pending` 并在 `evidence` 说明，后续要不要加枚举我们三个再定）；证据放原文片段，不要编造。
- `ip_status` 只能是 `granted`、`pending`、`published`、`unknown`；论文默认 `unknown`。

## 3. `capability_profiles_v0.1-thin.jsonl`

一行一个成果：

```json
{"achievement_id": "ach_openalex_W4210818813", "language": "zh", "text": "该工作围绕硫化物固态电解质……", "text_hash": "<可选，导入器会补算>", "method": "llm", "model": "qwen3.8-flash", "prompt_version": "v1"}
```

规则：

- `language` 只能是 `zh` 或 `en`；本冲刺只做 `zh`。
- `text_id` 和 `text_type` **由导入器生成**：`txt_{achievement_id}_capability_profile_{lang}`，`text_type` 按语言取 `capability_profile_zh` 或 `capability_profile_en`。
- `text_hash` 可省略；省略时导入器用 `scripts/common/llm_client.py` 的 `text_hash()` 补算，**推荐直接用它算**，这样和向量侧的 `embedding.text_hash` 一致。
- 画像长度 150—250 字，不是逐字翻译，是面向产业语言的技术能力摘要。

## 4. 导入命令

```bash
python scripts/data/load_db.py --dsn "$DATABASE_URL" \
  --labeled data/processed/achievements_labeled_v0.1-thin.jsonl \
  --profiles data/processed/capability_profiles_v0.1-thin.jsonl
```

`--check` 也会校验这两个文件（存在时），不连库。缺文件不报错，只在覆盖率检查里体现。
