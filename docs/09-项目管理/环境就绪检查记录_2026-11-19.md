## 5. 镜像导入说明

本机 Docker Desktop 拉取 `pgvector/pgvector:pg16` 时卡在 `Pulling fs layer`（registry blob 跳转到 CDN 后 TLS 连接异常）。处理方式：

1. 用宿主机网络通过 registry HTTP API 获取 manifest 和 16 层 blob。
2. 逐层校验 `sha256`，解压后校验 `rootfs.diff_ids`。
3. 组装成 `docker load` 可用的 tar，导入为 `pgvector/pgvector:pg16`。
4. `docker compose up -d --wait db`，容器 `aim-pgvector` 状态 healthy。

本机保留了离线包（仓库外，443 MB），Docker 重置后可用 `docker load -i` 恢复。其他成员优先使用镜像站；失败时按 `环境与密钥共享方案.md` §5.1 使用离线包。
