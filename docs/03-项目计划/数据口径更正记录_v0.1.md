## 1. BGE-M3 维度

- 计划书写“BGE-M3 768 维”。
- **BGE-M3 的 dense 向量是 1024 维**（多语言、最大输入 8192 tokens）。768 维通常对应 BGE-base-zh 等模型。
- 后续统一为：**BGE-M3 1024 维**，或备选 `qwen3.7-text-embedding-flash` 1024 维；两者不得混用。
- pgvector 表、Embedding 记录和匹配结果都按 1024 维建；`embedding.dim` 必须落库。

## 4. 对后续文档的要求

1. 需求规格书的数据来源、数据量、字段、标签体系统一引用 `data/spec/data_contract_v0.1.md` 和 `taxonomy_v0.1.md`。
2. 设计报告的向量维度写 1024；数据库设计包含 raw/curated/derived 三层和版本三元组。
3. 测试报告的数据质量用例引用 `data/manifests/`、`data/processed/` 的清单和统计，不引用未实际生成的数据。
4. 过程总结报告说明：计划书定稿中的 768 维为笔误，已在数据契约中更正；不影响项目范围和进度。
5. 答辩材料明确：成果数据为真实论文元数据，摘要经清洗/截断；中文画像为机器生成；需求/企业为模拟数据。
6. 开题报告只作历史提交材料；其中的质量指标、接口时延等口径不自动沿用，以定稿计划书和 `data/spec/` 为准。
